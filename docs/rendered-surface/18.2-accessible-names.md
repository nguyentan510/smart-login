# 18.2 — A name for every control

Spec: [`../rendered-surface.md`](../rendered-surface.md), decision 3. Status:
[`../refactor-plan.md`](../refactor-plan.md).

**Goal.** Turn rule 2 green. Two controls in the account card have no accessible
name, and both are the same box.

## Files

- `templates/partials/account/contact.php`
- `assets/css/omniwp.css` — if the label needs one line

## Steps

1. The OTP code box gets an `id` and a visible `<label>`, the same as every
   other field on the card. One per contact panel, so the id carries the channel
   the way `sl-contact-phone` and `sl-contact-email` already do.
2. The placeholder stays or goes on its own merits — it was standing in for a
   label and is now standing beside one. Decide it in the commit, not here.

## Acceptance

- Rule 2 green
- Rule 4 still green: the new ids are unique across a full account render, and
  the new `for` resolves
- Every other suite at its previous count, and the string catalogue regenerated

## Not in scope

`aria-label` as the fix. The spec argues why: it names the box for a screen
reader and leaves a sighted user with a hint that vanishes when they type.

---

## Outcome

```text
Rule 2 — every focusable control has an accessible name (18.2)
  (green — no output)

Rendered surface: 12 passed, 1 failed, 0 pending   (was 11 / 2)
```

A visible `<label>` reading "Mã xác thực", one per channel, with the id carrying
the channel the way `sl-contact-phone` and `sl-contact-email` already do. Rule 4
stays green across a full account render: two panels, two ids, both unique, both
resolving from their `<label for>`.

### The placeholder went rather than staying beside the label

It said the same thing the label says, and `maxlength` already carries the
length. That is the placeholder rule this project settled on in Phase 17's
answer: format or example, never a repeat of the label.

### It shows up in the keyboard walk

18.4's tab-order reading names the box twice — `<input text> Mã xác thực` at
positions 10 and 16 of 31. Before this sub-phase those two entries read
`(unnamed)`, which is what an assistive technology would have announced.
