# 23.2 Menu Item Editor Fields — Phase 23 Brief

Tạo class `SmartMenuFields` nằm tại `includes/Admin/class-smart-menu-fields.php`.

## Key Responsibilities
- Hook vào `wp_nav_menu_item_custom_fields` để bổ sung các tùy chọn cài đặt trực tiếp trên từng Nav Menu Item:
  - **Visibility**: Radio/Select (*Tất cả / Chỉ khách chưa đăng nhập / Chỉ thành viên đã đăng nhập*).
  - **Render Mode**: Select (*Simple Link / Rich Account Dropdown*).
- Hook vào `wp_update_nav_menu_item` để sanitize và lưu trữ `_ow_smart_menu_visibility` và `_ow_smart_menu_mode` vào post meta của nav menu item.
