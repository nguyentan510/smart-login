# 23.0 Guard Rails — Phase 23 Brief

Xây dựng bộ quy tắc kiểm thử tự động cho Phase 23 Smart Menu tại `tests/smart-menu/run-smart-menu-tests.php`.

## Requirements & Assertions
1. **Rule 1**: Định dạng URL của các Smart Menu Presets phải bắt đầu bằng `#smart-`.
2. **Rule 2**: Metabox ID đăng ký trên `nav-menus.php` phải là `add-omniwp-menu`.
3. **Rule 3**: `SmartMenuMetaBox` phải được hook vào `admin_head-nav-menus.php` hoặc `load-nav-menus.php`.
4. **Rule 4**: `SmartMenuFields` lưu meta key `_ow_smart_menu_visibility` và `_ow_smart_menu_mode` thông qua hook `wp_update_nav_menu_item`.
5. **Rule 5**: Trang đăng xuất (`#smart-logout`) không bao giờ lưu cứng URL mà phải render dynamic thông qua `wp_logout_url()`.
6. **Rule 6**: Dynamic Auth Switcher (`#smart-auth-switcher`) chuyển đổi nhãn và link tương ứng theo `is_user_logged_in()`.
7. **Rule 7**: Menu items có thuộc tính Visibility `guest` phải ẩn khi người dùng đã đăng nhập.
8. **Rule 8**: Menu items có thuộc tính Visibility `logged_in` phải ẩn khi khách chưa đăng nhập.
9. **Rule 9**: Nút kích hoạt Modal Smart Login Popup (`#omniwp`) phải nhận class `sl-login-trigger`.
10. **Rule 10**: Phase 21 Rich Dropdown mode phải tái sử dụng `:root` design tokens và `IconSet`.
