# 23.5 Verification & Promotion — Phase 23 Brief

Hoàn tất kiểm thử, tổng hợp kết quả và nâng cấp test suite.

## Key Responsibilities
- Chạy syntax lint: `php tests/run-lint.php`.
- Chạy coding standards: `php tests/run-phpcs.php`.
- Chạy toàn bộ test runner: `php tests/run-all.php`.
- Chuyển `smart-menu` suite trong `tests/run-all.php` từ `spec` thành `required`.
- Tạo `walkthrough.md` tổng kết quá trình kiểm thử.
