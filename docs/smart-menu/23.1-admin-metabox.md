# 23.1 Admin Metabox — Phase 23 Brief

Tạo class `SmartMenuMetaBox` nằm tại `includes/Admin/class-smart-menu-metabox.php` hiển thị Metabox **Smart Menu** trên màn hình WordPress Nav Menus (`wp-admin/nav-menus.php`).

## Key Responsibilities
- Hook vào `admin_head-nav-menus.php` và đăng ký metabox bằng `add_meta_box()`.
- Hiển thị danh sách 5 nhóm preset items bằng `wp_nav_menu_item_link_meta_box()`.
- Hỗ trợ Ajax "Add to Menu" chuẩn của WordPress.
