# 23.4 Visibility & Auth Switcher — Phase 23 Brief

Mở rộng `SmartMenuRenderer` xử lý logic Auth State nâng cao.

## Key Responsibilities
1. **Visibility Filter**:
   - Lọc bỏ menu item có visibility = `guest` khi `is_user_logged_in()` là true.
   - Lọc bỏ menu item có visibility = `logged_in` khi `is_user_logged_in()` là false.
2. **Auth Switcher (`#smart-auth-switcher`)**:
   - Khi chưa đăng nhập: Title = "Đăng nhập / Đăng ký", class = `sl-login-trigger`.
   - Khi đã đăng nhập: Title = Tên hiển thị / SĐT thành viên, URL = trang tài khoản.
   - Nếu Mode = `dropdown` (Rich Account Dropdown): Tích hợp sub-menu hoặc `<details>` dropdown từ Phase 21.
