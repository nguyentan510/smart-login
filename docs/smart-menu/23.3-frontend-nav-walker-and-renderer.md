# 23.3 Frontend Nav Walker & Renderer — Phase 23 Brief

Tạo class `SmartMenuRenderer` nằm tại `includes/Frontend/class-smart-menu-renderer.php`.

## Key Responsibilities
- Hook vào `wp_setup_nav_menu_item` và `wp_nav_menu_objects`.
- Nhận diện các menu items có URL chứa anchor `#smart-*`.
- Render dynamic URLs:
  - `#smart-logout` -> `wp_logout_url()`.
  - `#omniwp` -> Gán class `sl-login-trigger` và URL `#`.
  - `#smart-account` -> Dẫn tới URL Account Hub.
