# 17.7 — The fraction

Spec: [`../account-card.md`](../account-card.md), decision 7. Status:
[`../refactor-plan.md`](../refactor-plan.md).

**Goal.** Turn rule 7 green. "Hoàn thiện 4/6" needs a denominator, and the
denominator moves with five settings.

## Files

- `includes/Auth/class-profile-completion-service.php` — `status()`
- `templates/partials/account/status.php`
- `assets/css/smart-login.css` — the meter

## Steps

1. Each branch in `status()` that decides a field applies already runs; count
   there. `total` is every field in scope for this account, `done` is
   `total` minus what is missing.
2. The notice renders `done/total` and a meter. Two attributes carry the value
   for anything that is not looking at pixels: `role="progressbar"` with
   `aria-valuenow` / `aria-valuemax`.
3. No template counts anything.

## Acceptance

- Rule 7 green, both halves
- `total` moves when a setting moves — asserted with `profile.dob` off and on,
  because a denominator that is secretly a constant passes every other assertion
- `done === total` exactly when the account is complete and has nothing
  recommended outstanding
- Every other suite at its previous count

## Not in scope

Gamifying it. A meter that says 4/6 is a statement of fact; a badge that
congratulates somebody for reaching 6/6 is a different feature.
