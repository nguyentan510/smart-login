# 12.0 — Guard rails

Spec: [`../provider-surface.md`](../provider-surface.md). Status:
[`../refactor-plan.md`](../refactor-plan.md).

**Goal.** Land the rules red before 12.1 and 12.2 exist.

These go into `tests/identity/run-admin-tests.php` rather than a new suite. The
provider badge rule already lives there from the early fix, the screen is what
they assert on, and a fourth suite for three rules costs more than it explains —
the same judgement 10.7's lifecycle rules made when they rode in the delivery
suite.

## Files

- `tests/identity/run-admin-tests.php`
- No production file is touched.

## Steps

Three rules.

1. **The master switch is in the header, not the table.** The `enabled` checkbox
   must render inside `sl-provider-card__header`. Asserted on position rather
   than presence, because it is already present — level with Client ID, which is
   the defect.

2. **A policy that governs both cards renders before both cards.**
   `providers.auto_link_email`'s input must appear earlier in the markup than the
   first `sl-provider-card`. Red today: it is a section below the grid.

3. **A test round trip cannot sign anybody in.** A transaction created in test
   mode must not reach `SessionIssuer` or `AccountProvisioner`. This is the whole
   safety argument of 12.2, and it is the rule that has to exist before the code
   does — a diagnostic that quietly provisions an account is worse than no
   diagnostic.

   Expressed twice, because neither half is sufficient: structurally, that
   `callback()` returns before the issue path when the transaction is a test;
   behaviourally, that driving a test callback leaves the session issuer
   untouched.

## Acceptance

Rules 1 and 2 fail against today's markup. Rule 3 reports PENDING with the test
mode named as its blocker — not a vacuous pass, which is the mistake 10.0 made
with its rule 5 and 11.0 made again with its rule 3.

`php tests/run-all.php` — every other suite unchanged. The admin suite goes red
by exactly the number of new assertions that fail, and no other count moves.

## Not in scope

Any production change.
